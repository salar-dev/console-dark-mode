Privacy Policy

Dark Mode for Play Console & App Store Connect · Last updated 6 November 2026

This extension does not collect, store, transmit or sell any personal data.

What the extension does

It applies a dark colour theme to two websites only:

  • https://play.google.com/console/* (Google Play Console)
  • https://appstoreconnect.apple.com/* (App Store Connect)

The extension reads the pages' stylesheets (colours declared in CSS) in order to generate a dark counterpart. It does not read page content, form fields, app data, account information or anything else from those pages, and nothing is sent anywhere.

Data stored

Your preferences (master switch, per-console switches, "follow system appearance") are stored with chrome.storage.sync. This data stays within your browser profile and, if you are signed in to Chrome with sync enabled, is synchronised by Google between your own devices. It never reaches the developer of this extension.

Permissions

PermissionWhy it is needed
storageRemember your toggles.
Host access to the two sites aboveRequired by Chrome to inject the theme stylesheet and the small scripts that turn it on and off and keep it in sync with the page's own styling.

Credit link

While the theme is active, a small "Dark Mode By: Salar Dev" link is added to the site footer. It is a plain link to the developer's GitHub profile; it loads nothing and reports nothing.

Network

The extension makes no network requests of its own. There are no analytics, no remote configuration and no third-party scripts.

Changes to this policy

If the extension's behaviour ever changes in a way that affects your data, this page and the Chrome Web Store listing will be updated before the new version is published.
